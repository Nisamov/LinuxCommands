=== ldapsearch
Herramienta de shell para abrir una conexión a un servidor LDAP y realizar búsquedas.

:category: host_shared_storage
[.metadata]
{
  "description": "Lleva a cabo una búsqueda LDAP basada en filtros específicos y devuelve los resultados en formato LDIF.",
  "usage": "ldapsearch -H ldap://localhost -x -b 'dc=empresa,dc=com' '(uid=usuario)'",
  "options": {
    "-x": "-x (Simple auth), -H (URI del servidor), -b (Base DN)",
    "-D": "-D (Bind DN), -W (Pedir contraseña), -w (Contraseña en texto)",
    "-LLL": "-LLL (Formato LDIF limpio), -A (Solo atributos, sin valores)",
    "filtros": "Soporta operadores lógicos como (&), (|) y (!)"
  }
}

[source,bash]
----
# Búsqueda simple de todos los objetos en una base específica
ldapsearch -x -b "dc=ejemplo,dc=com" -H ldap://localhost
----

conexion:: `-x -H -b` Definir el método de conexión y el punto de inicio (Base DN)

[source,bash]
----
# Buscar un usuario específico dentro de una unidad organizativa concreta
ldapsearch -x -H ldaps://ldap.server.com -b "ou=users,dc=empresa,dc=es" "(uid=usuario1)"
----

autenticacion:: `-D -W -w` Credenciales para búsquedas que requieren privilegios

[source,bash]
----
# Realizar búsqueda autenticado como administrador (solicita contraseña)
ldapsearch -x -D "cn=admin,dc=ejemplo,dc=com" -W -b "dc=ejemplo,dc=com" "(cn=John*)"
----

salida:: `-LLL -A` Formatear la respuesta para scripts o visualización limpia

[source,bash]
----
# Listar solo los correos de los usuarios en formato LDIF limpio
ldapsearch -x -LLL -b "dc=com" "(objectClass=person)" mail
----

filtros:: `(&)(|)(!)` Uso de operadores lógicos para búsquedas complejas

[source,bash]
----
# Buscar usuarios que pertenezcan al departamento IT Y tengan cuenta activa
ldapsearch -x -b "dc=com" "(&(ou=IT)(objectClass=posixAccount))"
----
