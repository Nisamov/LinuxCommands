=== slapcat
Exportar el contenido de una base de datos LDAP a formato LDIF para copias de seguridad.

:category: host_shared_storage
[.metadata]
{
  "description": "Herramienta para generar volcados de la base de datos LDAP directamente desde los archivos de datos, sin pasar por el protocolo LDAP.",
  "usage": "slapcat -n 1 -l backup_diario.ldif",
  "options": {
    "-n": "Seleccionar base de datos por número",
    "-b": "Especificar el DN base a exportar",
    "-l": "Guardar salida en un archivo",
    "-o": "Opciones adicionales de formato",
    "-d": "Modo debug para depuración",
    "-c": "Continuar en caso de errores",
    "-v": "Modo verbose (detallado)",
    "-F": "Especificar directorio de configuración"
  }
}

[source,bash]
----
# Realizar un volcado completo de la base de datos principal a un archivo
slapcat -l backup_total.ldif
----

-n:: `-n` Seleccionar base de datos por número de índice

[source,bash]
----
# Exportar la base de datos número 1 (usualmente la de datos de usuario)
slapcat -n 1
----

-b:: `-b` Especificar el DN base a exportar

[source,bash]
----
# Exportar únicamente una rama específica del directorio
slapcat -b "ou=users,dc=example,dc=com"
----

-l:: `-l` Guardar la salida directamente en un archivo LDIF

[source,bash]
----
# Crear un archivo de respaldo en la ruta especificada
slapcat -l /var/backups/ldap_backup.ldif
----

-o:: `-o` Definir opciones adicionales de configuración

[source,bash]
----
# Exportar sin limitar el ancho de línea en el archivo resultante
slapcat -o ldif-wrap=no
----

-d:: `-d` Activar el modo debug para detectar fallos de lectura

[source,bash]
----
# Ejecutar con nivel de depuración 1 (rastreo de llamadas)
slapcat -d 1
----

-c:: `-c` Modo de recuperación ante errores

[source,bash]
----
# Continuar la exportación aunque se encuentren entradas corruptas
slapcat -c -l backup_emergencia.ldif
----

-v:: `-v` Modo verbose para ver el progreso

[source,bash]
----
# Mostrar estadísticas y detalles durante el proceso de volcado
slapcat -v
----

-F:: `-F` Especificar la ubicación del directorio de configuración (slapd.d)

[source,bash]
----
# Usar una ruta de configuración no estándar para la exportación
slapcat -F /etc/ldap/config_especifica.d -n 1
----
