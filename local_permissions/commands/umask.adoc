=== umask

Define la máscara de bits que determina los permisos que no se asignarán a los archivos y directorios recién creados en el proceso actual.

==== Fundamentos Técnicos

A diferencia de `chmod`, que establece permisos absolutos, `umask` actúa como un **filtro**. Cuando un proceso realiza la llamada al sistema `open()` o `mkdir()`, el kernel calcula los permisos finales mediante la operación lógica:

* Modo Base (Archivos): `666` (octal) `rw-rw-rw-`
* Modo Base (Directorios): `777` (octal) `rwxrwxrwx`

==== Análisis de Máscaras Comunes

[cols="1,2,2,3", options="header"]
|===
| umask | Binario (u/g/o) | Permisos (Dir) | Implicación de Seguridad
| `0022` | `000 010 010` | `755 / rwxr-xr-x` | Estándar: Escritura solo para propietario.
| `0027` | `000 010 111` | `750 / rwxr-x---` | Entornos compartidos: Grupo lee, otros nada.
| `0077` | `000 111 111` | `700 / rwx------` | Alta seguridad: Solo acceso al propietario.
|===

==== Implementación en Shell

[source,bash]
----
# Obtener representación octal de 4 dígitos (incluyendo sticky bit/SUID/SGID)
umask
# Representación simbólica (bits permitidos, no filtrados)
# Resultado típico: u=rwx,g=rx,o=rx
umask -S
# Configuración de máscara para sesión actual
# Filtra bit de escritura para grupo y todos los bits para otros
umask 027
----

==== Persistencia y Herencia

El valor de `umask` es un atributo del proceso. Se hereda del proceso padre (normalmente el shell) y se define generalmente en los archivos de inicialización:
1.  `/etc/profile` o `/etc/bashrc` (Global)
2.  `~/.bashrc` o `~/.bash_profile` (Usuario)
