Levantar un *stack de monitorización* que recoja métricas SNMP de *2 targets Linux* y genere una *alerta automática* cuando uno de los targets deje de responder.

== VM-MON: stack de monitorización

=== Nota importante

El flujo correcto es:

----
Prometheus → /snmp → snmp_exporter → (SNMP) → targets
----

Por ello:

* El *job SNMP* en Prometheus apunta a `127.0.0.1:9116`
* El *target real* se pasa como parámetro.

== Instalar Prometheus y dependencias

[source,bash]
----
sudo apt update
sudo apt install -y prometheus snmp curl
----

== Configurar módulos SNMP para snmp_exporter

Archivo:

[source]
----
/etc/prometheus/snmp.yml
----

Crear el archivo:

[source,bash]
----
sudo tee /etc/prometheus/snmp.yml >/dev/null <<'YAML'
modules:
  if_mib:
    walk:
      - 1.3.6.1.2.1.1
      - 1.3.6.1.2.1.2
    version: 2
    auth:
      community: public
YAML
----

== Instalar snmp_exporter (binario) + servicio

[source,bash]
----
cd /tmp
VER="0.27.0"
wget -q https://github.com/prometheus/snmp_exporter/releases/download/v${VER}/snmp_exporter-${VER}.linux-amd64.tar.gz
tar -xzf snmp_exporter-${VER}.linux-amd64.tar.gz

sudo mv snmp_exporter-${VER}.linux-amd64/snmp_exporter /usr/local/bin/
sudo mkdir -p /etc/snmp_exporter
sudo cp /etc/prometheus/snmp.yml /etc/snmp_exporter/snmp.yml
----

=== Crear servicio systemd

[source,bash]
----
sudo tee /etc/systemd/system/snmp_exporter.service >/dev/null <<'UNIT'
[Unit]
Description=Prometheus SNMP Exporter
After=network-online.target
Wants=network-online.target

[Service]
User=prometheus
Group=prometheus
ExecStart=/usr/local/bin/snmp_exporter --config.file=/etc/snmp_exporter/snmp.yml
Restart=on-failure

[Install]
WantedBy=multi-user.target
UNIT
----

=== Activar servicio

[source,bash]
----
sudo systemctl daemon-reload
sudo systemctl enable --now snmp_exporter
sudo systemctl status snmp_exporter --no-pager
----

=== Verificar métricas

[source,bash]
----
curl -s http://localhost:9116/metrics | head
----

== Prometheus: scrape de SNMP vía snmp_exporter

Editar:

[source]
----
/etc/prometheus/prometheus.yml
----

Añadir:

[source,yaml]
----
scrape_configs:
  - job_name: "snmp"
    metrics_path: /snmp
    params:
      module: [if_mib]
    static_configs:
      - targets:
          - 192.168.56.11
          - 192.168.56.12
    relabel_configs:
      - source_labels: [__address__]
        target_label: __param_target
      - source_labels: [__param_target]
        target_label: instance
      - target_label: __address__
        replacement: 127.0.0.1:9116
----

Reiniciar Prometheus:

[source,bash]
----
sudo systemctl restart prometheus
----

== Alertmanager + regla de alerta

Instalar:

[source,bash]
----
sudo apt install -y alertmanager
----

=== Reglas de Prometheus

[source]
----
/etc/prometheus/rules.yml
----

[source,bash]
----
sudo tee /etc/prometheus/rules.yml >/dev/null <<'YAML'
groups:
- name: snmp-alerts
  rules:
  - alert: SNMPTargetDown
    expr: up{job="snmp"} == 0
    for: 30s
    labels:
      severity: critical
    annotations:
      summary: "Target SNMP caído"
      description: "No responde SNMP: {{ $labels.instance }}"
YAML
----

=== Cargar reglas en Prometheus

Editar:

[source]
----
/etc/prometheus/prometheus.yml
----

[source,yaml]
----
rule_files:
  - /etc/prometheus/rules.yml

alerting:
  alertmanagers:
    - static_configs:
        - targets: ["127.0.0.1:9093"]
----

Reiniciar servicios:

[source,bash]
----
sudo systemctl restart prometheus
sudo systemctl restart alertmanager
----
