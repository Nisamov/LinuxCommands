=== newgrp
Cambia el GID real del usuario actual durante una sesión de login.

:category: local_group
[.metadata]
{
  "description": "Permite a un usuario cambiar su grupo primario actual a otro grupo del que sea miembro. Los nuevos archivos creados tras el comando pertenecerán a este nuevo grupo.",
  "usage": "newgrp [GRUPO]",
  "options": {
    "[grupo]": "Nombre del grupo al que se desea cambiar",
    "-": "Simula un inicio de sesión completo (reinicializa el entorno)",
    "exit": "Comando para finalizar la sesión del nuevo grupo y volver al anterior"
  }
}

[source,bash]
----
# Cambiar el grupo primario actual a 'developers'
newgrp developers
----

-:: `newgrp - [grupo]` Reinicializar el entorno de usuario al cambiar de grupo

[source,bash]
----
# Cambiar de grupo como si fuera un nuevo inicio de sesión (limpia variables)
newgrp - developers
----

Verificación:: Uso de `id` para confirmar el cambio de GID

[source,bash]
----
# Verificar qué grupo primario está activo actualmente
id -gn
----

Uso práctico:: Creación de archivos con el nuevo grupo

[source,bash]
----
# Al cambiar de grupo, los archivos creados heredan el nuevo GID
newgrp projectteam
touch informe_compartido.txt
ls -l informe_compartido.txt
# El grupo del archivo será 'projectteam'
----

Finalización:: Volver al grupo original

[source,bash]
----
# El comando newgrp abre una sub-shell; para salir, se usa exit
exit
----
