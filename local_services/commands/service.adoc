=== service
Gestionar servicios en sistemas con SysVinit (alternativa a systemctl).

:category: local_services
[.metadata]
{
  "description": "Gestionar servicios y trabajos (jobs) en sistemas con SysVinit (Ubuntu 9.10-14.10, RHEL 6).",
  "usage": "service [OPCIONES] SERVICIO",
  "options": {
    "--list": "Listar servicios y sus estados",
    "--start": "Iniciar un servicio",
    "--stop": "Detener un servicio",
    "--restart": "Reiniciar un servicio",
    "--reload": "Recargar configuración de un servicio",
    "--status": "Ver estado de un servicio",
    "--emit": "Emitir evento a servicios"
  }
}

[source,bash]
----
# Ver estado de un servicio
service ssh status
----

-Comandos básicos:: Gestión tradicional de servicios

[source,bash]
----
# Iniciar servicio
service nginx start

# Detener servicio
service apache2 stop

# Reiniciar servicio
service mysql restart

# Recargar configuración
service haproxy reload

# Verificar estado
service postfix status
----

-Listar servicios:: Ver servicios disponibles

[source,bash]
----
# Listar todos los servicios disponibles
service --status-all

# Listar servicios con estado
service --status-all | grep +

# Los símbolos indican estado:
# [+] Servicio ejecutándose
# [-] Servicio detenido
# [?] Estado desconocido
----
