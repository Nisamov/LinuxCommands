=== find
Buscar archivos y directorios en una jerarquía de directorios según diversos criterios.

:category: local_filesystem

[source,bash]
----
# Buscar todos los archivos .txt en el directorio actual y subdirectorios
find . -name "*.txt"
----

-name / -iname:: `-name` (exacto) o `-iname` (insensible a mayúsculas)

[source,bash]
----
# Buscar "Foto.jpg", "foto.JPG" o "FOTO.jpg"
find /home/usuario/Imagenes -iname "foto.jpg"
----

-type:: `-type` Filtra el tipo de objeto en el sistema de archivos

[source,bash]
----
# Listar solo directorios que contengan la palabra "backup"
find /mnt/datos -type d -name "*backup*"
----

-mtime / -atime / -ctime:: `+/-N` Filtros temporales (en días)

[source,bash]
----
# Buscar archivos modificados hace menos de 24 horas (-1)
find /etc -mtime -1

# Buscar archivos cuyo contenido no ha cambiado en más de 30 días (+30)
find /var/www -mtime +30
----

-size:: `-size` Filtra por peso del archivo (c: bytes, k: KiB, M: MiB, G: GiB)

[source,bash]
----
# Buscar archivos mayores a 100 Megabytes
find / -type f -size +100M
----

-perm:: `-perm` Busca archivos con permisos específicos (octal o simbólico)

[source,bash]
----
# Buscar archivos con permisos de ejecución para todos (777)
find . -perm 777
----

-user / -group:: Filtra por propietario o grupo

[source,bash]
----
# Buscar archivos que pertenecen al usuario 'www-data'
find /var/www -user www-data
----

-maxdepth / -mindepth:: Controlan la recursividad de la búsqueda

[source,bash]
----
# Buscar solo en el directorio actual, sin entrar en subcarpetas
find /tmp -maxdepth 1 -name "*.tmp"
----

-exec / -ok:: Ejecuta una acción sobre cada coincidencia. `{}` es el marcador del archivo y `\;` finaliza el comando.

[source,bash]
----
# Buscar archivos .log antiguos y comprimirlos
find /var/log -name "*.log" -mtime +30 -exec gzip {} \;

# Buscar y borrar pidiendo confirmación
find . -name "test_*" -ok rm {} \;
----

-delete:: `-delete` Borra directamente los resultados encontrados

[source,bash]
----
# Limpiar todos los archivos temporales .bak (Peligro: no pide confirmación)
find . -name "*.bak" -delete
----

-print0:: `-print0` Útil para enviar resultados a `xargs -0` evitando errores con espacios

[source,bash]
----
# Borrar de forma segura archivos que puedan tener espacios en el nombre
find . -name "archivo sucio.*" -print0 | xargs -0 rm
----

Operadores Lógicos:: Permiten combinar múltiples criterios (`-and`, `-or`, `-not`)

[source,bash]
----
# Buscar archivos que sean .sh Y que pertenezcan a root
find /bin -name "*.sh" -and -user root

# Buscar archivos que NO sean directorios
find . -not -type d
----
