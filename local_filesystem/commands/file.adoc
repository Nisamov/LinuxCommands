=== file
Determinar el tipo de fichero según su contenido.

:category: local_filesystem
[.metadata]
{
  "description": "Determinar el tipo de fichero según su contenido.",
  "usage": "file [OPCIONES] RUTA",
  "options": {
    "-b": "Mostrar tipo sin el nombre del fichero",
    "-i": "Mostrar tipo MIME",
    "-L": "Seguir enlaces simbólicos",
    "--mime-type": "Mostrar sólo MIME type"
  }
}

[source,bash]
----
# Mostrar tipo de un fichero
file fichero.txt
----

* -b:: `file -b` Mostrar tipo sin el nombre del fichero

[source,bash]
----
# Mostrar sólo el tipo
file -b fichero.txt
----

* -i:: `file -i` Mostrar tipo MIME

[source,bash]
----
# Mostrar tipo MIME
file -i fichero.txt
----

* -L:: `file -L` Seguir enlaces simbólicos

[source,bash]
----
# Seguir enlace simbólico
file -L enlace.txt
----

* --mime-type:: `file --mime-type` Mostrar sólo MIME type

[source,bash]
----
# Mostrar sólo MIME type
file --mime-type fichero.txt
----
