=== chattr
Cambiar los atributos de archivos en sistemas de ficheros Linux (ext2, ext3, ext4, etc.).

:category: local_filesystem
[.metadata]
{
  "description": "Modifica atributos especiales del sistema de archivos que van más allá de los permisos tradicionales (lectura, escritura, ejecución). Permite hacer archivos inmutables o de solo suma.",
  "usage": "chattr +i archivo_critico.conf",
  "options": {
    "+": "Añadir un atributo específico",
    "-": "Quitar un atributo específico",
    "=": "Establecer solo los atributos indicados",
    "-R": "Aplicar cambios de forma recursiva en directorios",
    "-V": "Modo verbose (detallado), muestra la versión del programa",
    "-f": "Suprimir la mayoría de los mensajes de error",
    "+i": "Atributo: Inmutable (no se puede borrar, renombrar ni modificar)",
    "+a": "Atributo: Append-only (solo permite añadir datos al final)",
    "+A": "Atributo: No actualizar el tiempo de acceso (atime)",
    "+c": "Atributo: Comprimido automáticamente en el disco",
    "+C": "Atributo: No Copy-on-Write (NOCOW)",
    "+d": "Atributo: No incluir en volcados de dump (respaldos)",
    "+e": "Atributo: Usar extents para la gestión de bloques",
    "+s": "Atributo: Borrado seguro (sobrescribe con ceros al eliminar)",
    "+S": "Atributo: Actualización síncrona (escribe a disco inmediatamente)",
    "+u": "Atributo: Indeletable (permite recuperar el archivo tras borrarlo)"
  }
}

[source,bash]
----
# Proteger un archivo contra cualquier modificación, incluso por parte de root
chattr +i /etc/shadow
----

-R:: `-R` Aplicar los cambios recursivamente a todos los archivos y subdirectorios

[source,bash]
----
# Hacer que toda una carpeta de logs sea de solo lectura/añadido
chattr -R +a /var/log/aplicacion/
----

-V:: `-V` Modo detallado que indica qué atributos se están aplicando

[source,bash]
----
# Cambiar atributos viendo el resultado de la operación
chattr -V +i fichero.txt
----

+i / -i:: `+/-i` Activar o desactivar el atributo de inmutabilidad

[source,bash]
----
# Quitar la protección para poder editar un archivo protegido
chattr -i /etc/resolv.conf
----

+a / -a:: `+/-a` Activar o desactivar el modo de "solo añadir" (útil para logs)

[source,bash]
----
# Impedir que se borren líneas antiguas de un log, permitiendo solo nuevas
chattr +a /var/log/auth.log
----

+A / -A:: `+/-A` Controlar si se actualiza el registro de último acceso (atime)

[source,bash]
----
# Mejorar rendimiento de disco evitando escribir la hora de cada lectura
chattr +A base_de_datos.db
----

+s / -s:: `+/-s` Borrado seguro para datos altamente sensibles

[source,bash]
----
# Asegurar que los bloques del archivo se limpien al borrarlo
chattr +s claves_secretas.txt
----

+c:: `+c` Indica al kernel que comprima el archivo de forma transparente

[source,bash]
----
# Ahorrar espacio en disco mediante compresión nativa del FS
chattr +c archivo_muy_grande.txt
----

+C:: `+C` Desactivar Copy-on-Write (específico para sistemas como Btrfs)

[source,bash]
----
# Optimizar el rendimiento de archivos de máquinas virtuales o DB
chattr +C imagen_vm.qcow2
----

+d:: `+d` Evitar que el comando 'dump' procese este archivo

[source,bash]
----
# Excluir archivos temporales de las copias de seguridad del sistema
chattr +d /tmp/archivo_temporal
----

+u:: `+u` Permite la recuperación del archivo tras ser eliminado (Undelete)

[source,bash]
----
# Facilitar el rescate de datos en caso de borrado accidental
chattr +u tesis_final.doc
----
