=== md5sum
Calcular y verificar resúmenes de mensajes MD5 (128 bits).

:category: local_filesystem
[.metadata]
{
  "description": "Genera una 'huella digital' única de un archivo. Si el contenido del archivo cambia, aunque sea un solo bit, el hash resultante será completamente distinto. Es el estándar clásico para verificar que una descarga no se ha corrompido.",
  "usage": "md5sum archivo.zip > archivo.zip.md5",
  "options": {
    "-b": "Leer en modo binario (por defecto en casi todos los sistemas)",
    "-t": "Leer en modo texto (trata los saltos de línea de forma distinta)",
    "-c": "Verificar los hashes contenidos en un archivo contra los archivos reales",
    "--tag": "Formato de salida estilo BSD (MD5 (archivo) = hash)",
    "--status": "No mostrar salida; el éxito se comprueba mediante el código de salida",
    "--quiet": "No imprimir 'OK' por cada archivo verificado correctamente",
    "--warn": "Advertir sobre líneas de sumas de comprobación mal formateadas",
    "--strict": "Salir con error si alguna línea del archivo de sumas está mal",
    "--help": "Mostrar la ayuda del comando",
    "--version": "Mostrar información de la versión"
  }
}

[source,bash]
----
# Generar el hash de un archivo
md5sum instalador.exe
# Salida: 4906f343468695034c4f3468903e1a8e  instalador.exe
----

-c:: `-c` (check) Lee un archivo que contiene rutas y hashes, y comprueba si coinciden con los archivos actuales.

[source,bash]
----
# Verificar la integridad de todos los archivos listados en el índice
md5sum -c sumas_de_verificacion.md5
# Salida esperada: archivo1.zip: LA SUMA COINCIDE
----

--tag:: `--tag` Crea una salida más descriptiva que indica el algoritmo utilizado explícitamente.

[source,bash]
----
# Formato legible para humanos
md5sum --tag reporte.pdf
# Salida: MD5 (reporte.pdf) = 54e9...
----

--status:: `--status` Ideal para automatización; no ensucia la terminal con texto.

[source,bash]
----
# Usar en un script para tomar decisiones según el resultado
if md5sum -c --status lista.md5; then
    echo "Archivos íntegros"
else
    echo "Corrupción detectada"
fi
----

-b / -t:: Diferencia entre modo binario y texto.

[source,bash]
----
# En Linux no suele haber diferencia, pero en Windows afecta a los finales de línea (\r\n)
md5sum -b imagen.iso
----

Seguridad (Nota Crítica):: MD5 ya no se considera seguro contra ataques malintencionados (colisiones).

[source,bash]
----
# Para seguridad criptográfica, usa algoritmos de la familia SHA:
sha256sum archivo.tar.gz
----

Uso con Pipes:: Calcular el hash de un flujo de datos directamente.

[source,bash]
----
# Verificar el hash de un archivo remoto sin descargarlo físicamente
curl -s http://ejemplo.com/archivo.iso | md5sum
----
