=== basename
Extraer el nombre del fichero o directorio a partir de una ruta completa.

:category: local_filesystem
[.metadata]
{
  "description": "Elimina los directorios principales de una ruta para devolver solo el nombre base, permitiendo además quitar sufijos específicos.",
  "usage": "basename -s '.sh' /usr/local/bin/script.sh",
  "options": {
    "-a": "Procesar múltiples argumentos como rutas individuales",
    "-s": "Eliminar un sufijo específico del final del nombre",
    "-z": "Finalizar cada línea de salida con un carácter nulo (NUL)",
    "--help": "Mostrar la ayuda del comando y salir",
    "--version": "Mostrar información de la versión y salir"
  }
}

[source,bash]
----
# Obtener el nombre del fichero desde una ruta completa
basename /home/usuario/documentos/nota.txt
----

-a:: `-a` (multiple) Permite pasar varias rutas como argumentos independientes

[source,bash]
----
# Extraer el nombre de tres archivos distintos en una sola ejecución
basename -a /etc/passwd /var/log/syslog /bin/bash
----

-s:: `-s` (suffix) Elimina el sufijo indicado si coincide con el final del nombre

[source,bash]
----
# Obtener el nombre del archivo eliminando la extensión .conf
basename -s .conf /etc/apache2/apache2.conf
----

-z:: `-z` (zero) Sustituye el salto de línea por un carácter nulo (\0)

[source,bash]
----
# Útil para tuberías (pipelines) con xargs -0 para manejar nombres con espacios
basename -az /fotos/vacaciones\ 2024.jpg /fotos/perro.png
----

--help:: `--help` Muestra la pantalla de ayuda con la sintaxis y opciones

[source,bash]
----
# Consultar rápidamente el manual de uso en terminal
basename --help
----

--version:: `--version` Indica la versión instalada de coreutils

[source,bash]
----
# Verificar la versión del binario basename
basename --version
----

SUFIJO (Legacy):: Forma clásica de eliminar una extensión (sin usar el flag -s)

[source,bash]
----
# Sintaxis: basename RUTA SUFIJO (Solo funciona para una ruta)
basename /ruta/archivo.log .log
----
