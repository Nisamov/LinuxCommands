=== bzip2
Empaquetamiento de múltiples archivos y directorios.

:category: local_filesystem
[.metadata]
{
  "description": "Herramienta para comprimir y descomprimir archivos con alta compresión.",
  "usage": "bzip2 [OPCIONES] archivo",
  "options": {
    "-c": "Escribir salida a stdout",
    "-d": "Descomprimir archivo",
    "-k": "Mantener archivo original",
    "-v": "Mostrar información de progreso",
    "-z": "Comprimir archivo"
  }
}

[source,bash]
----
# Empaquetado de archivos
bzip2 archivo.txt

# Desempaquetar archvivos
bunzip2 archivo.txt.bz2
----

-c:: `bzip -c archivo > archivo.txt.bz2` Comprimir manteniendo archivos originales
