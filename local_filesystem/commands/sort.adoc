=== sort
Ordenar líneas de archivos de texto de forma alfabética, numérica o personalizada.

:category: local_filesystem
[.metadata]
{
  "description": "Lee el contenido de un archivo o de la entrada estándar y lo devuelve ordenado. Es el compañero perfecto de 'uniq' para procesar listas y de 'find/ls' para organizar salidas de sistema.",
  "usage": "sort -n -k 2 archivo.txt",
  "options": {
    "-n": "Ordenar por valor numérico (1, 2, 10 en lugar de 1, 10, 2)",
    "-r": "Invertir el resultado de la ordenación (descendente)",
    "-u": "Único: elimina líneas duplicadas en el resultado final",
    "-k": "Definir la columna (key) por la que se desea ordenar (ej: -k 2)",
    "-t": "Establecer el carácter separador de campos (por defecto es el espacio/tabulador)",
    "-f": "Ignorar diferencias entre mayúsculas y minúsculas (fold case)",
    "-h": "Ordenar números con sufijos legibles (ej: 2K, 1G, 50M)",
    "-V": "Orden de versión: maneja correctamente números dentro del texto (v1.2, v1.10)",
    "-o": "Escribir el resultado en un archivo (permite que sea el mismo archivo de origen)",
    "-R": "Ordenar de forma aleatoria (random)",
    "-c": "Comprobar si el archivo ya está ordenado (no ordena, solo avisa)"
  }
}

[source,bash]
----
# Ordenar alfabéticamente (comportamiento por defecto)
sort nombres.txt
----

-n:: `-n` (numeric) Sin esta opción, la shell compara carácter a carácter ("1" viene antes que "2").

[source,bash]
----
# Ordenar una lista de IDs o cantidades
sort -n cantidades.txt
----

-k / -t:: Combinación para trabajar con archivos delimitados (como CSV o /etc/passwd).

[source,bash]
----
# Ordenar los usuarios del sistema por su UID (columna 3, separada por ':')
sort -t ':' -k 3 -n /etc/passwd
----

-u:: `-u` (unique) más eficiente que usar `sort | uniq`, realiza la limpieza durante el proceso de ordenación.

[source,bash]
----
# Obtener una lista limpia de dominios sin repetidos
sort -u dominios.log
----

-h:: `-h` (human-numeric) Diseñado para trabajar con salidas de comandos como `du` o `df`.

[source,bash]
----
# Ver qué carpetas ocupan más espacio (orden descendente de tamaño legible)
du -sh * | sort -rh
----

-V:: `-V` (version)

[source,bash]
----
# Ordenar correctamente: v1.1, v1.2, v1.10
ls | sort -V
----

-o:: `-o` (output) Permite leer y escribir en el mismo archivo de forma segura.

[source,bash]
----
# Ordenar un archivo y guardar los cambios sobre sí mismo
sort lista.txt -o lista.txt
----

-R:: `-R` (random) Barajar líneas de un archivo.

[source,bash]
----
# Seleccionar un ganador aleatorio de una lista
sort -R participantes.txt | head -n 1
----
