=== rm
Eliminar archivos o directorios de forma permanente.

:category: local_filesystem
[.metadata]
{
  "description": "Elimina las referencias a archivos del sistema. Por defecto, no elimina directorios. Ten en cuenta que en Linux, 'rm' no mueve los archivos a una papelera; los borra definitivamente.",
  "usage": "rm -rf /ruta/al/directorio",
  "options": {
    "-r": "Recursivo: elimina directorios y todo su contenido de forma jerárquica",
    "-f": "Forzar: ignora archivos inexistentes y nunca solicita confirmación",
    "-i": "Interactivo: solicita confirmación antes de cada eliminación",
    "-I": "Interactivo limitado: pregunta una sola vez antes de borrar más de tres archivos o al borrar recursivamente",
    "-v": "Modo detallado (verbose): muestra el nombre de cada archivo que se va borrando",
    "-d": "Eliminar directorios vacíos (similar a rmdir)",
    "--preserve-root": "Fallo de seguridad: impide que el comando actúe sobre '/' (activado por defecto)",
    "--no-preserve-root": "Desactivar la protección de la raíz del sistema (extremadamente peligroso)",
    "--one-file-system": "Al borrar recursivamente, omitir directorios que estén en otros sistemas de archivos"
  }
}

[source,bash]
----
# Eliminar un archivo simple
rm notas.txt
----

-r / -R:: `-r` (recursive) es obligatorio para borrar carpetas que contienen otros archivos o subcarpetas.

[source,bash]
----
# Borrar un proyecto entero incluyendo todos sus archivos internos
rm -r mi_proyecto_viejo/
----

-f:: `-f` (force) suprime las advertencias si el archivo no existe o tiene permisos de solo lectura (siempre que tú seas el dueño).

[source,bash]
----
# Borrar archivos temporales sin que el script se detenga por errores de "no encontrado"
rm -f /tmp/*.tmp
----

-i vs -I:: Control de confirmación para evitar errores accidentales.

[source,bash]
----
# -i: Pregunta por CADA archivo (tedioso para muchos archivos)
rm -i *.jpg

# -I: Pregunta una vez si vas a borrar más de 3 archivos (más equilibrado)
rm -I *.log
----

-v:: `-v` (verbose) te da un informe en tiempo real de lo que está desapareciendo.

[source,bash]
----
# Confirmar visualmente que la limpieza se está realizando
rm -rv carpeta_basura/
----

-d:: `-d` permite a `rm` borrar una carpeta, pero solo si está totalmente vacía.

[source,bash]
----
# Intentar borrar una carpeta solo si no tiene contenido
rm -d carpetas_vacias_*
----

La opción nuclear: -rf:: La combinación más potente y peligrosa en manos de un administrador.

[source,bash]
----
# Borra TODO en la ruta especificada de forma inmediata y sin preguntas
# ¡Úsalo con extrema precaución!
rm -rf ./cache_inservible
----

--preserve-root:: Es una salvaguarda moderna para evitar el famoso error `rm -rf /` que destruiría el sistema operativo.

[source,bash]
----
# Esto fallará gracias a la protección por defecto:
rm -rf /
----
