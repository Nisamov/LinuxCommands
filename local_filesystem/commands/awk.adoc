=== awk
Procesar y analizar texto estructurado por columnas.

:category: local_filesystem
[.metadata]
{
  "description": "Herramienta de procesamiento de texto para analizar y manipular datos estructurados por columnas mediante un lenguaje de programación propio.",
  "usage": "awk -F':' '$3 > 1000 {print $1, $NF}' /etc/passwd",
  "options": {
    "-F": "Definir el separador de campos (FS)",

  }

[source,bash]
----
# Ejemplo básico: Mostrar la primera columna de un fichero
awk '{print $1}' datos.txt
----

-F:: `-F` Define el carácter que separa las columnas (por defecto espacio/tabulador)

[source,bash]
----
# Usar el carácter ':' como separador para leer el archivo de usuarios
awk -F: '{print $1}' /etc/passwd
----

-v:: `-v` Permite pasar variables desde la shell al interior de awk

[source,bash]
----
# Pasar un umbral de búsqueda como variable
limite=100
awk -v var=$limite '$3 > var' ventas.txt
----

-f:: `-f` Indica a awk que debe leer las instrucciones desde un script .awk

[source,bash]
----
# Ejecutar un script complejo guardado en un archivo externo
awk -f procesador.awk datos.csv
----

print:: `print` Comando principal para dar salida a los datos procesados

[source,bash]
----
# Imprimir columnas específicas con un texto literal añadido
awk '{print "Usuario:", $1, "ID:", $3}' lista.txt
----

condicion:: Permite ejecutar bloques de código solo si se cumple un requisito

[source,bash]
----
# Imprimir líneas cuyo tercer campo sea exactamente 'ADMIN'
awk '$3 == "ADMIN" {print $0}' accesos.log
----

BEGIN:: `BEGIN {}` Acciones que se ejecutan una sola vez al inicio

[source,bash]
----
# Imprimir una cabecera formateada antes de los datos
awk 'BEGIN {print "NOMBRE\tCORREO"} {print $1 "\t" $2}' usuarios.txt
----

END:: `END {}` Acciones que se ejecutan una sola vez al terminar de leer

[source,bash]
----
# Contar el total de líneas procesadas al final
awk '{count++} END {print "Total de registros:", count}' archivo.txt
----

NR:: `NR` (Number of Record) Variable que contiene el índice de la línea actual

[source,bash]
----
# Mostrar el número de línea seguido del contenido
awk '{print NR, $0}' documento.txt
----

NF:: `NF` (Number of Fields) Variable con el total de columnas de la línea actual

[source,bash]
----
# Imprimir el último campo de cada línea, sea cual sea su posición
awk '{print $NF}' log_variable.txt
----

OFS:: `OFS` (Output Field Separator) Define cómo se separan las columnas al imprimir

[source,bash]
----
# Cambiar el separador de salida a una flecha para mejorar legibilidad
awk 'BEGIN {OFS=" -> "} {print $1, $2}' lista.txt
----

ORS:: `ORS` (Output Record Separator) Define qué carácter separa cada línea de salida

[source,bash]
----
# Unir todas las líneas en una sola separada por comas
awk 'BEGIN {ORS=", "} {print $0}' nombres.txt
----
