=== tar
Empaquetar y comprimir archivos y directorios en un solo contenedor.

[source,bash]
----
# El comando más común: Crear un backup comprimido de una carpeta
tar -czvf mi_proyecto.tar.gz ./proyecto
----

Diferencia entre Empaquetar y Comprimir::
* **Empaquetar (.tar)**: Une muchos archivos en uno solo (como meter cosas en una caja). El tamaño total es la suma de los archivos.
* **Comprimir (.gz, .bz2, .xz)**: Reduce el tamaño del paquete (como usar bolsas al vacío). `tar` utiliza herramientas externas para esto mediante sus flags.

-z, -j, -J:: La elección del algoritmo depende de si prefieres velocidad o ahorro de espacio.

|===
| Flag | Algoritmo | Extensión | Características
| `-z` | **Gzip** | .tar.gz | El más rápido y compatible.
| `-j` | **Bzip2** | .tar.bz2 | Mejor compresión que gzip, pero más lento.
| `-J` | **XZ** | .tar.xz | Máxima compresión, consumo alto de CPU.
|===

-x:: `tar -x` (extract) detecta automáticamente el tipo de compresión en versiones modernas de Linux, por lo que a veces basta con `-xf`.

[source,bash]
----
# Extraer un archivo en una carpeta específica (que debe existir)
tar -xzvf backup.tar.gz -C /tmp/restauracion/
----

-t:: `-t` (test/list) es vital para verificar qué hay dentro de un archivo descargado de internet antes de "ensuciar" tu directorio actual.

[source,bash]
----
# Ver qué contiene el archivo sin extraer nada
tar -tvf desconocido.tar.gz
----

--exclude:: Muy útil para ignorar carpetas pesadas o innecesarias como `node_modules`, `.git` o cachés.

[source,bash]
----
# Empaquetar código fuente ignorando dependencias y git
tar -czvf codigo.tar.gz --exclude='node_modules' --exclude='.git' .
----

--strip-components:: Usar cuando el archivo comprimido tiene una estructura de carpetas interna que no quieres replicar exactamente.

[source,bash]
----
# Si el tar contiene 'apps/web/config/file.txt', esto extrae solo 'config/file.txt'
tar -xvf backup.tar -C . --strip-components=2
----

Combinación con Pipes:: `tar` puede enviar su salida a la red o a otros comandos.

[source,bash]
----
# Enviar una carpeta a otro servidor vía SSH sin crear un archivo intermedio
tar -czf - ./mi_web | ssh usuario@servidor "tar -xzf - -C /var/www/"
----
