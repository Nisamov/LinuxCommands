=== shred
Destruir el contenido de archivos mediante sobrescritura repetida.

:category: local_filesystem
[.metadata]
{
  "description": "Sobrescribe los archivos especificados repetidamente con patrones de datos aleatorios para hacer que la recuperación de datos sea extremadamente difícil, incluso mediante examen físico del soporte magnético.",
  "usage": "shred -u -n 5 secreto.txt",
  "options": {
    "-n": "Número de veces que se sobrescriben los datos (predeterminado: 3)",
    "-u": "Eliminar (de-vincular) el archivo después de sobrescribirlo",
    "-z": "Añadir una sobrescritura final con ceros para ocultar que el archivo fue triturado",
    "-v": "Modo detallado: muestra el progreso de cada pasada de sobrescritura",
    "-s": "Triturar solo el número de bytes especificado (acepta sufijos como K, M, G)",
    "-f": "Forzar: cambia los permisos del archivo si es necesario para permitir la escritura",
    "-x": "No redondear el tamaño del archivo hacia arriba al bloque más cercano",
    "--random-source": "Usar un archivo específico (como /dev/urandom) como fuente de aleatoriedad"
  }
}

[source,bash]
----
# Triturar un archivo con 3 pasadas aleatorias (el archivo permanece en el disco, pero ilegible)
shred datos_bancarios.csv
----

-u:: `-u` (remove) Si no se usa, el archivo "shredded" seguirá apareciendo en `ls`, aunque su contenido sea basura aleatoria.

[source,bash]
----
# Sobrescribir y borrar físicamente el rastro del archivo del directorio
shred -u evidencia.jpg
----

-z:: `-z` (zero) Después de las pasadas aleatorias, escribe una capa de ceros.

[source,bash]
----
# El estándar de oro para borrado seguro: 5 pasadas, borrar archivo y ocultar con ceros
shred -uvz -n 5 documento_confidencial.pdf
----

-v:: `-v` (verbose) permite ver en qué "pasada" se encuentra el proceso.

[source,bash]
----
# Ver cómo shred aplica los patrones de bits en tiempo real
shred -v disk_dump.img
# Salida: shred: disk_dump.img: pasada 1/3 (random)...
----

-s:: `-s` (size) Permite destruir solo una parte de un archivo o dispositivo.

[source,bash]
----
# Destruir solo el primer Gigabyte de una partición entera
sudo shred -v -s 1G /dev/sdb1
----
