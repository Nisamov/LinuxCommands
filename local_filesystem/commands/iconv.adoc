=== iconv
Convertir la codificación de caracteres de archivos o flujos de texto.

:category: local_filesystem
[.metadata]
{
  "description": "Transforma texto de una codificación (encoding) a otra. Es esencial para corregir problemas de visualización de caracteres (mojibake) entre sistemas Windows, Linux y formatos antiguos.",
  "usage": "iconv -f ISO-8859-1 -t UTF-8 archivo.txt",
  "options": {
    "-f": "Especificar la codificación de origen (From-code)",
    "-t": "Especificar la codificación de destino (To-code)",
    "-o": "Escribir el resultado en un archivo en lugar de la salida estándar",
    "-l": "Listar todas las codificaciones de caracteres soportadas",
    "-c": "Omitir silenciosamente los caracteres que no se pueden convertir",
    "-s": "Modo silencioso: suprimir mensajes de advertencia sobre errores",
    "--verbose": "Mostrar información sobre el progreso y estadísticas",
    "--byte-subst": "Sustituir bytes no convertibles con una secuencia específica",
    "--widechar-subst": "Sustituir caracteres anchos no convertibles"
  }
}

[source,bash]
----
# Convertir un archivo de Windows (CP1252) a Linux estándar (UTF-8)
iconv -f CP1252 -t UTF-8 archivo_windows.txt > archivo_linux.txt
----

-f / -t:: `-f` (from) y `-t` (to) definen el puente de conversión

[source,bash]
----
# Convertir de UTF-8 a la codificación clásica de Europa Occidental
iconv -f UTF-8 -t ISO-8859-15 entrada.txt
----

Modificadores de destino:: Añadir `//TRANSLIT` o `//IGNORE` al final del código destino (`-t`)

[source,bash]
----
# //TRANSLIT: Aproximar caracteres (ej: '©' se convierte en '(c)')
iconv -f UTF-8 -t ASCII//TRANSLIT texto.txt

# //IGNORE: Eliminar cualquier carácter que no quepa en el destino
iconv -f UTF-8 -t ASCII//IGNORE texto.txt
----

-o:: `-o` (output) Permite especificar el archivo de salida directamente sin usar redirecciones de shell (`>`)

[source,bash]
----
# Convertir y guardar en un nuevo archivo
iconv -f UTF-8 -t UTF-16 -o salida_win.txt entrada.txt
----

-c:: `-c` Descarta los caracteres que no pueden ser convertidos en lugar de detener el proceso con un error

[source,bash]
----
# Forzar la conversión de un archivo corrupto ignorando errores
iconv -c -f UTF-8 -t ISO-8859-1 archivo_danado.txt
----

-l:: `-l` (list) Muestra la lista completa de nombres y alias de codificaciones que tu sistema reconoce

[source,bash]
----
# Buscar si el sistema soporta una codificación específica de IBM
iconv -l | grep -i "IBM"
----

Uso con find:: Convertir de forma masiva todos los archivos de un directorio

[source,bash]
----
# Convertir todos los .txt de una carpeta a UTF-8 (requiere precaución)
find . -name "*.txt" -exec sh -c 'iconv -f ISO-8859-1 -t UTF-8 "{}" > "{}.tmp" && mv "{}.tmp" "{}"' \;
----

Detección previa:: Antes de usar iconv, es útil saber qué tenemos entre manos

[source,bash]
----
# Usar el comando 'file' para intentar adivinar la codificación actual
file -i documento.txt
----
