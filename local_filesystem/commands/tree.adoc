=== tree
Listar ficheros con estructura de árbol.

:category: local_filesystem
[.metadata]
{
  "description": "Listar ficheros con estructura de árbol.",
  "usage": "tree [OPCIONES]",
  "options": {
    "-d": "Mostrar solo directorios",
    "-f": "Mostrar los archivos con su respectiva ruta",
    "-a": "Mostrar archivos ocultos",
    "-u": "Mostrar propietario de cada archivo",
    "-g": "Mostrar grupos de ficheros",
    "-h": "Mostrar peso de cada archivo"
  }
}

[source,bash]
----
# Listar directorio en forma de árbol
tree
----

-d:: `tree -d` Mostrar solo directorios

[source,bash]
----
# Mostrar sólo directorios
tree -d
----

-f:: `tree -f` Mostrar los archivos con su respectiva ruta

[source,bash]
----
# Mostrar archivos con rutas
tree -f
----

-a:: `tree -a` Mostrar archivos ocultos

[source,bash]
----
# Incluir archivos ocultos
tree -a
----

-u:: `tree -u` Mostrar propietario de cada archivo

[source,bash]
----
# Mostrar propietarios
tree -u
----

-g:: `tree -g` Mostrar grupos de ficheros

[source,bash]
----
# Mostrar grupo de cada fichero
tree -g
----

-h:: `tree -h` Mostrar peso de cada archivo

[source,bash]
----
# Mostrar tamaños legibles
tree -h
----
