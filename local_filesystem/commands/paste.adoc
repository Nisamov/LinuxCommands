=== paste
Escribir líneas de varios archivos de forma paralela (columna a columna).

:category: local_filesystem
[.metadata]
{
  "description": "Une las líneas correspondientes de cada archivo indicado, separándolas por tabuladores en la salida estándar. Es la herramienta ideal para crear tablas a partir de listas separadas.",
  "usage": "paste -d ',' nombres.txt edades.txt > datos.csv",
  "options": {
    "-d": "Especificar una lista de delimitadores para usar en lugar de tabuladores",
    "-s": "Serializar: pega todas las líneas de un solo archivo en una única línea larga",
    "-z": "Las líneas terminan con el carácter nulo (NUL) en lugar de nueva línea",
    "--help": "Mostrar la ayuda del comando",
    "--version": "Mostrar la versión del programa"
  }
}

[source,bash]
----
# Unir dos listas: la primera será la columna 1 y la segunda la columna 2
paste nombres.txt apellidos.txt
----

-d:: `-d <delimitadores>` Cambia el tabulador por el carácter que elijas. Si pones varios, los irá rotando.

[source,bash]
----
# Crear un formato CSV sencillo usando comas
paste -d ',' nombres.txt telefonos.txt

# Usar delimitadores alternos (guion y luego dos puntos)
paste -d '-:' file1.txt file2.txt file3.txt
----

-s:: `-s` (serial) En lugar de pegar archivos en paralelo, toma un archivo y pone todas sus líneas seguidas horizontalmente.

[source,bash]
----
# Convertir una lista vertical en una fila separada por espacios
paste -s -d ' ' lista_items.txt
----

Uso con Stdin (el guion `-`):: Permite leer de la entrada estándar y organizar los datos en columnas.

[source,bash]
----
# Tomar una lista de 6 elementos y ponerlos en 2 columnas de 3
cat lista.txt | paste - -

# Convertir un listado simple en una tabla de 3 columnas
ls | paste - - -
----
