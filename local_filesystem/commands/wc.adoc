=== wc
Contar líneas, palabras y bytes de uno o varios ficheros.

:category: local_filesystem
[.metadata]
{
  "description": "Calcula estadísticas de recuento para los archivos proporcionados. Si se pasan varios archivos, genera una línea para cada uno y un total acumulado al final. Es una pieza clave en scripts para validar si un proceso generó datos o para contar ocurrencias de un patrón.",
  "usage": "ls -l | wc -l",
  "options": {
    "-l": "Lines: muestra el número de saltos de línea (útil para contar registros)",
    "-w": "Words: muestra el número de palabras (delimitadas por espacios)",
    "-c": "Bytes: muestra el tamaño total en bytes",
    "-m": "Chars: muestra el número de caracteres (útil con codificaciones multibyte como UTF-8)",
    "-L": "Max-line-length: muestra la longitud (en caracteres) de la línea más larga del archivo",
    "--files0-from": "Lee los nombres de los archivos desde un archivo específico terminado en NUL"
  }
}

[source,bash]
----
# Contar líneas, palabras y bytes
wc fichero.txt
----

-l:: `wc -l` Mostrar número de líneas

[source,bash]
----
# Contar líneas
wc -l fichero.txt
----

-w:: `wc -w` Mostrar número de palabras

[source,bash]
----
# Contar palabras
wc -w fichero.txt
----

-c:: `wc -c` Mostrar número de bytes

[source,bash]
----
# Contar bytes
wc -c fichero.txt
----

-m:: `wc -m` Mostrar número de caracteres

[source,bash]
----
# Contar caracteres
wc -m fichero.txt
----

-L:: `wc -L` Mostrar la longitud de la línea más larga

[source,bash]
----
# Longitud de la línea más larga
wc -L fichero.txt
----

--help:: `wc --help` Mostrar ayuda

[source,bash]
----
# Mostrar ayuda
wc --help
----
