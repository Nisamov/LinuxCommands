=== xz
Compresor y descompresor de archivos de alta eficiencia basado en los algoritmos LZMA/LZMA2.

:category: local_filesystem
[.metadata]
{
  "description": "Utiliza algoritmos de compresión sin pérdida para reducir drásticamente el tamaño de los archivos. Aunque requiere más memoria y CPU para comprimir que sus competidores, la descompresión es muy rápida y el ahorro de espacio es superior.",
  "usage": "xz -9 archivo.iso",
  "options": {
    "-z": "Compress: fuerza la compresión (comportamiento por defecto)",
    "-d": "Decompress: descompone el archivo .xz (equivalente a unxz)",
    "-k": "Keep: mantiene el archivo original después de la operación (por defecto se borra)",
    "-l": "List: muestra información técnica (tamaño original, comprimido, ratio, integridad)",
    "-c": "Stdout: escribe el resultado en la salida estándar en lugar de crear un archivo",
    "-t": "Test: verifica la integridad del archivo comprimido mediante sumas de comprobación (CRC)",
    "-0...-9": "Compression level: ajusta el nivel de 0 (rápido) a 9 (máximo ahorro de espacio)",
    "-e": "Extreme: intenta exprimir aún más la compresión usando más tiempo de CPU",
    "-T": "Threads: utiliza múltiples núcleos para acelerar el proceso (ej: -T 0 para usar todos)"
  }
}

[source,bash]
----
# Uso básico: comprime y reemplaza el archivo original por 'datos.sql.xz'
xz datos.sql
----

-d:: `xz -d` Decomprimir archivos.

[source,bash]
----
# Descomprimir un archivo manteniendo el comprimido
xz -dk backup.tar.xz
----

-l:: `-l` (list) Conocer cuánto espacio has ahorrado realmente sin tener que descomprimir el archivo completo.

[source,bash]
----
# Ver el ratio de compresión y el método utilizado
xz -l kernel-source.tar.xz
----

-k:: Por defecto, `xz` se comporta como `gzip`: "traga" el original y devuelve el comprimido. Usa `-k` (keep) si quieres conservar ambos.

[source,bash]
----
# Comprimir un log pero dejar el original intacto por si acaso
xz -k system.log
----

-0 a -9:: El nivel `-6` es el predeterminadoo. El nivel `-9` puede requerir mucha memoria RAM (hasta 674 MB para el diccionario de compresión).

[source,bash]
----
# Usar el modo extremo para archivos que se van a distribuir masivamente
xz -9e software_v1.tar
----

-T:: Por defecto, `xz` es monohilo (usa un solo núcleo). En procesadores modernos, puedes acelerar el proceso drásticamente.

[source,bash]
----
# Comprimir usando todos los núcleos disponibles del procesador
xz -T 0 archivo_gigante.img
----
