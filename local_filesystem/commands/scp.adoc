=== scp
Copia segura de archivos y directorios entre diferentes equipos a través de la red (Secure Copy).

:category: local_filesystem
[.metadata]
{
  "description": "Utiliza SSH para la transferencia de datos, proporcionando la misma autenticación y seguridad que una sesión de terminal remota. Permite copiar de local a remoto, de remoto a local, o incluso entre dos hosts remotos.",
  "usage": "scp -P 2222 archivo.zip usuario@servidor:/tmp/",

[source,bash]
----
# Enviar un archivo al servidor remoto
scp datos.tar.gz admin@10.0.0.5:/home/admin/backups/
----

Sentido de la copia:: `scp` siempre sigue la estructura `scp [ORIGEN] [DESTINO]`.

[source,bash]
----
# Traer un archivo desde el servidor a mi ordenador actual (.)
scp usuario@servidor:/var/log/syslog .

# Copiar entre dos servidores remotos (los datos pasan por tu máquina)
scp user1@host1:/file.txt user2@host2:/dest/
----

-r:: `-r` (recursive) para mover carpetas. Sin él, `scp` omitirá los directorios.

[source,bash]
----
# Descargar toda la carpeta de imágenes del servidor
scp -r web_user@webserver:/var/www/html/images ~/Descargas/
----

-P:: `-P <port>` (mayúscula). Muchos servidores cambian el puerto 22 por seguridad.

[source,bash]
----
# Transferir a un servidor que escucha en el puerto 443
scp -P 443 config.json root@servidor_seguro:/etc/app/
----

-l:: `-l <limit>` Evita saturar la conexión de red de la oficina o casa.

[source,bash]
----
# Limitar la subida a unos 50 KB/s (el valor se da en Kbit/s, 400 Kbit ≈ 50 KB)
scp -l 400 archivo_gigante.iso user@host:/storage/
----

-i:: `-i <identity_file>` Para conexiones automáticas o servidores con llaves.

[source,bash]
----
# Usar una llave específica para un servidor de Amazon AWS
scp -i ~/claves/aws_key.pem index.html ec2-user@instance-ip:/var/www/html/
----

-C:: `-C` (compress) Ahorra tiempo si transfieres archivos de texto, logs o SQL sin comprimir.

[source,bash]
----
# Acelerar la copia de un volcado de base de datos SQL muy grande
scp -C dump_enero.sql user@remote_backup:/sqldumps/
----
