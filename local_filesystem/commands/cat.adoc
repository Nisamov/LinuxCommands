=== cat
Concatenar y mostrar el contenido de ficheros.

:category: local_filesystem
[.metadata]
{
  "description": "Herramienta para concatenar y mostrar el contenido de ficheros.",
  "usage": "cat [OPCIONES] archivo",
  "options": {
    "-n": "Numerar líneas de salida",
    "-b": "Numerar solo líneas no vacías",
    "-A": "Mostrar caracteres especiales (tabuladores, finales de línea)"
  }
}

[source,bash]
----
# Mostrar un fichero
cat fichero.txt
----

-n:: `cat -n` Numerar líneas de salida

[source,bash]
----
# Mostrar con numeración de líneas
cat -n fichero.txt
----

-b:: `cat -b` Numerar sólo líneas no vacías

[source,bash]
----
# Numerar sólo líneas no vacías
cat -b fichero.txt
----

-A:: `cat -A` Mostrar caracteres especiales

[source,bash]
----
# Mostrar caracteres especiales (tabuladores, finales de línea)
cat -A fichero.txt
----
