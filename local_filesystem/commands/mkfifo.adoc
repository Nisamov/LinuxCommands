=== mkfifo
Crear una tubería con nombre (FIFO) en el sistema de ficheros.

:category: local_filesystem
[.metadata]
{
  "description": "Crear una tubería con nombre (FIFO) en el sistema de ficheros.",
  "usage": "mkfifo [OPCIONES] NOMBRE_TUBERIA",
  "options": {
    "-m": "Establecer permisos de la tubería (modo)",
    "-Z": "Establecer contexto de seguridad (SELinux)"
  }
}

[source,bash]
----
# Crear una tubería llamada 'tuberia'
mkfifo tuberia
----

- (uso):: `mkfifo <nombre>` Crear tubería con nombre

[source,bash]
----
# Escribir en la tubería desde un proceso y leer en otro
echo "Hola" > tuberia &
cat < tuberia
----
