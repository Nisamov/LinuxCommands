=== split
Dividir un archivo grande en fragmentos más pequeños de tamaño o longitud definida.

:category: local_filesystem
[.metadata]
{
  "description": "Fragmenta archivos basándose en el número de líneas, tamaño en bytes o número total de archivos resultantes. Por defecto, genera archivos con el prefijo 'x' (xaa, xab, xac...).",
  "usage": "split -b 100M archivo_grande.zip parte_",
  "options": {
    "-l": "Dividir el archivo según el número de líneas por fragmento",
    "-b": "Dividir por tamaño en bytes (acepta sufijos K, M, G, T)",
    "-n": "Dividir en un número exacto de fragmentos (ej: -n 5)",
    "-d": "Usar sufijos numéricos (00, 01...) en lugar de alfabéticos (aa, ab...)",
    "-a": "Longitud del sufijo (por defecto 2 dígitos; ej: -a 4 para 0001)",
    "--additional-suffix": "Añadir una extensión personalizada al final de cada fragmento (ej: .part)",
    "--verbose": "Mostrar un mensaje cada vez que se crea un nuevo archivo de salida",
    "-t": "Usar un carácter separador de registros distinto al salto de línea"
  }
}

[source,bash]
----
# Uso básico: divide el archivo en trozos de 1000 líneas (por defecto)
split access.log
----

-l:: `-l <líneas>`Procesar archivos de texto o CSV de forma masiva sin saturar la memoria RAM.

[source,bash]
----
# Dividir una lista de 1 millón de correos en archivos de 50.000 líneas cada uno
split -l 50000 correos.txt fragmento_
----

-b:: `-b <tamaño>` El parámetro estándar para archivos binarios (ISO, imágenes, bases de datos).

[source,bash]
----
# Dividir un backup de 1GB en trozos de 200MB para subir a la nube
split -b 200M backup.tar.gz backup_part_
----

-d / -a:: Mejoran la legibilidad y organización de los archivos resultantes.

[source,bash]
----
# Generar archivos numerados con 3 dígitos (x000, x001, x002...)
split -d -a 3 logs_anuales.txt
----

--additional-suffix:: Permite que los fragmentos mantengan la extensión original.

[source,bash]
----
# Resultado: trozo_01.sql, trozo_02.sql...
split -d -l 1000 base_datos.sql trozo_ --additional-suffix=.sql
----

-n:: `-n <num>` Útil cuando sabes cuántos archivos quieres obtener pero no quieres calcular el tamaño de cada uno.

[source,bash]
----
# Dividir un archivo exactamente en 4 partes iguales
split -n 4 archivo.iso
----

[source,bash]
----
# Unir todos los fragmentos que empiezan por 'parte_' en un solo archivo
cat parte_* > archivo_recompuesto.zip

# Verificar que el archivo resultante es idéntico al original
md5sum archivo_grande.zip archivo_recompuesto.zip
----

Uso con Pipes::
`split` puede leer de la entrada estándar, lo que permite comprimir y dividir al mismo tiempo.

[source,bash]
----
# Comprimir una carpeta y dividir el resultado en trozos de 10MB sin crear el .tar.gz intermedio
tar -czf - /home/usuario/fotos | split -b 10M - fotos_part_
----
