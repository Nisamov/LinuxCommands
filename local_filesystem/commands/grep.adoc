=== grep
Buscar patrones de texto en archivos utilizando expresiones regulares.

:category: local_filesystem
[.metadata]
{
  "description": "Herramienta de búsqueda que filtra líneas de texto que coinciden con un patrón. Soporta desde búsquedas de texto simple hasta expresiones regulares complejas (POSIX y Perl).",
  "usage": "grep -rinE 'error|fail' /var/log",
  "options": {
    "-i": "Ignorar mayúsculas y minúsculas (ignore-case)",
    "-r": "Búsqueda recursiva en directorios y subdirectorios",

    "-l": "Mostrar solo los nombres de los archivos que contienen coincidencias",
    "-L": "Mostrar solo los nombres de los archivos que NO contienen coincidencias",
    "-c": "Mostrar el conteo total de líneas coincidentes por cada archivo",
    "-q": "Modo silencioso: no escribe nada, solo devuelve un código de salida (0 si hay éxito)",

[source,bash]
----
# Buscar una palabra específica en un archivo
grep "root" /etc/passwd
----

-i:: `-i` Permite encontrar el patrón sin importar si está en mayúsculas o minúsculas

[source,bash]
----
# Busca "ERROR", "error", "Error", etc.
grep -i "error" sistema.log
----

-r:: `-r` (o `-R`) Escanea todos los archivos dentro de una estructura de carpetas

[source,bash]
----
# Buscar una cadena en todo el código fuente del proyecto
grep -r "API_KEY" ./src
----

-v:: `-v` (invert-match) Filtra la salida para descartar lo que no nos interesa

[source,bash]
----
# Ver procesos del sistema ignorando los del usuario root
ps aux | grep -v "root"
----

-E:: `-E` (extended-regexp) Habilita el uso de operadores modernos como `|`, `+`, `?` y `()` sin escapar

[source,bash]
----
# Buscar líneas que contengan 'HTTP/1.1' o 'HTTP/2.0'
grep -E "HTTP/(1.1|2.0)" access.log
----

-o:: `-o` (only-matching) Extrae exclusivamente el fragmento que cumple la regla

[source,bash]
----
# Extraer todas las direcciones IP de un archivo de log (usando regex)
grep -oE "[0-9]{1,3}(\.[0-9]{1,3}){3}" access.log
----

-A, -B, -C:: Control de contexto para visualizar líneas adyacentes a la coincidencia

[source,bash]
----
# Mostrar el error y las 3 líneas siguientes para ver la causa
grep -A 3 "CRITICAL_ERROR" app.log

# Mostrar 2 líneas antes y 2 después (contexto total)
grep -C 2 "usuario_login" auth.log
----

-w:: `-w` (word-regexp) Evita coincidencias parciales (ej: busca 'vaca' pero no 'vacaciones')

[source,bash]
----
# Buscar la variable 'id' pero no 'identity' o 'uuid'
grep -w "id" script.py
----

-l / -L:: `-l` (files-with-matches) o `-L` (files-without-match) para auditoría de archivos

[source,bash]
----
# ¿Qué archivos de configuración contienen la palabra 'bind'?
grep -l "bind" /etc/*.conf
----

-c:: `-c` (count) Devuelve un resumen numérico en lugar del texto

[source,bash]
----
# Contar cuántas veces aparece una IP en el log de hoy
grep -c "192.168.1.50" access.log
----

-q:: `-q` (quiet) Ideal para condicionales en scripts de Bash

[source,bash]
----
# Comprobar si un usuario existe sin llenar la pantalla de texto
if grep -q "^usuario1:" /etc/passwd; then
    echo "El usuario existe"
fi
----

-P:: `-P` (perl-regexp) Permite usar funciones avanzadas como Lookahead o cuantificadores de Perl

[source,bash]
----
# Buscar texto entre comillas dobles
grep -P '(?<=").*?(?=")' archivo.json
----
