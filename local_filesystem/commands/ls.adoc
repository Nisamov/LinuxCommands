=== ls
Listar el contenido de directorios y mostrar información sobre archivos.

:category: local_filesystem

[source,bash]
----
# Listado básico en el directorio actual
ls
----

Estructura de salida detallada (ls -l)::
[source,bash]
----
# Ejemplo de salida de ls -l:
# -rw-r--r-- 1 usuario grupo 1024 mar 21 01:00 archivo.txt
# ^ (1)      ^ (2) ^ (3)  ^ (4) ^ (5)        ^ (6)
# (1) Permisos (2) Enlaces (3) Dueño (4) Grupo (5) Tamaño (6) Nombre
----

-l / -h / -a:: Combinación clásica para administración diaria

[source,bash]
----
# Ver todos los archivos, con tamaños legibles y detalles técnicos
ls -lah
----

-t / -r:: Gestionar archivos por fecha

[source,bash]
----
# Listar archivos modificados recientemente al final de la lista
ls -ltr
----

-S:: Identificar archivos pesados

[source,bash]
----
# Ver qué archivos ocupan más espacio en la carpeta actual
ls -lS
----

-d:: Inspeccionar el directorio, no lo que hay dentro

[source,bash]
----
# Útil para verificar permisos de una carpeta específica
ls -ld /home/usuario
----

-F:: Identificación visual rápida de tipos de archivos

[source,bash]
----
# Los directorios terminan en '/', ejecutables en '*', enlaces en '@'
ls -F
----

-v:: Ordenar versiones o series numéricas correctamente

[source,bash]
----
# Útil para listar archivos como 'foto1.jpg', 'foto2.jpg', 'foto10.jpg' en orden
ls -v
----

--time:: Consultar fechas de acceso o cambio de estado

[source,bash]
----
# Ver cuándo fue la última vez que se leyó (accedió) cada archivo
ls -l --time=atime
----

--block-size:: Forzar unidades de medida específicas

[source,bash]
----
# Mostrar todos los tamaños estrictamente en Megabytes
ls -l --block-size=M
----

--sort:: Alternativa explícita para ordenar

[source,bash]
----
# Agrupar archivos por su extensión
ls -l --sort=extension
----
