=== Operadores y Redirecciones
Símbolos especiales para controlar el flujo de datos y la lógica de ejecución en la shell.

:category: system_shell
[.metadata]
{
  "description": "Permiten manipular los tres flujos estándar (stdin, stdout, stderr) y encadenar comandos según su éxito o fracaso.",
  "usage": "comando1 | comando2 && comando3 > salida.txt",
  "options": {
    ">": "Redirigir salida estándar (stdout) a un archivo (sobrescribe)",

    "||": "Ejecución condicional: ejecuta el segundo comando solo si el primero falla",

[source,bash]
----
# Ejemplo combinado: buscar un texto y guardar errores en un log aparte
grep "patrón" archivo.txt > resultados.txt 2> errores.log
----

> / >>:: Redirección de salida. `>` trunca el archivo antes de escribir; `>>` preserva el contenido previo.

[source,bash]
----
# Crear un archivo nuevo con el listado
ls /etc > lista_config.txt

# Añadir la fecha actual al final del log sin borrar lo anterior
date >> registro_actividad.log
----

| (Pipe):: Conecta comandos para crear "pipelines" de procesamiento de datos.

[source,bash]
----
# Ver cuántas líneas del log contienen la palabra 'Accepted'
cat auth.log | grep "Accepted" | wc -l
----

2> / &>:: Control de errores. El descriptor `2` representa a `stderr`.

[source,bash]
----
# Descartar errores enviándolos al "agujero negro" del sistema
find / -name "*.conf" 2> /dev/null

# Guardar todo (salida y errores) en un solo archivo de log
comando_complejo &> salida_total.log
----

&& / ||:: Operadores lógicos de control. El éxito se define por un código de salida `0`.

[source,bash]
----
# &&: 'Si esto funciona, haz lo siguiente'
mkdir nueva_carpeta && cd nueva_carpeta

# ||: 'Si esto falla, haz lo siguiente'
ls archivo_critico.txt || echo "El archivo ha desaparecido"
----

< (Stdin):: Alimenta un comando con el contenido de un archivo en lugar de escribirlo por teclado.

[source,bash]
----
# Enviar el contenido de un archivo como cuerpo de un correo
mail -s "Reporte" admin@example.com < reporte.txt
----

&:: Libera la terminal permitiendo que el proceso corra "detrás" de la sesión actual.

[source,bash]
----
# Abrir el editor de texto y poder seguir usando la terminal inmediatamente
gedit notas.txt &
----

<<< (Here String):: Pasa una cadena de texto directamente a un comando que espera un archivo.

[source,bash]
----
# Convertir un texto a mayúsculas sin crear archivos intermedios
tr '[:lower:]' '[:upper:]' <<< "hola mundo"
----
