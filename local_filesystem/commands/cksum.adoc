=== cksum
Calcular y verificar sumas de comprobación (checksum) y conteo de bytes.

:category: local_filesystem
[.metadata]
{
  "description": "Calcula valores de redundancia cíclica (CRC) o hashes criptográficos para verificar la integridad de los archivos.",
  "usage": "cksum -a sha256 -c sumas.txt",
  "options": {
    "-a": "Especificar el algoritmo de hash (sysv, bsd, crc, md5, sha1, sha256, etc.)",
    "-c": "Verificar las sumas de comprobación desde un archivo",
    "-l": "Especificar la longitud del hash (solo para algoritmos como BLAKE2)",
    "-t": "Leer en modo texto (por defecto)",
    "-b": "Leer en modo binario",
    "-z": "Terminar cada línea de salida con un carácter nulo en lugar de nueva línea",
    "--status": "No mostrar salida, solo devolver el código de estado",
    "--quiet": "No imprimir 'OK' por cada archivo verificado correctamente",
    "--strict": "Salir con error si alguna suma está mal formateada",
    "--tag": "Crear una salida de estilo BSD (nombre del algoritmo al inicio)",
    "--ignore-missing": "No fallar ni mostrar avisos si faltan archivos",
    "--debug": "Indicar el algoritmo que se está utilizando",
    "--help": "Mostrar la ayuda del comando"
  }
}

[source,bash]
----
# Uso clásico: Obtener CRC (POSIX), tamaño en bytes y nombre del archivo
cksum documento.txt
----

-a:: `-a` (algorithm) Seleccionar el algoritmo de hash deseado

[source,bash]
----
# Calcular un hash SHA256 en lugar del CRC tradicional
cksum -a sha256 imagen_sistema.iso
----

-c:: `-c` (check) Leer sumas de comprobación desde un archivo y verificarlas

[source,bash]
----
# Comprobar que los archivos coinciden con las sumas guardadas previamente
cksum -c lista_verificacion.txt
----

-l:: `-l` (length) Ajustar la longitud de la suma (útil para BLAKE2b)

[source,bash]
----
# Generar un hash BLAKE2b limitado a 256 bits
cksum -a blake2b -l 256 archivo.zip
----

--quiet:: `--quiet` Suprimir los mensajes de confirmación 'OK'

[source,bash]
----
# Mostrar solo los errores detectados durante la verificación
cksum -c --quiet sumas.txt
----

--status:: `--status` Modo silencioso total, ideal para condicionales en scripts

[source,bash]
----
# Verificar integridad y usar el código de salida ($?) para decidir acciones
if cksum -c --status sumas.txt; then echo "Todo correcto"; fi
----

--tag:: `--tag` Formatear la salida con el nombre del algoritmo al principio

[source,bash]
----
# Generar una salida descriptiva compatible con el formato BSD
cksum --tag -a md5 datos.tar.gz
----

-z:: `-z` (zero) Finalizar cada línea con el carácter nulo (\0)

[source,bash]
----
# Generar salida segura para ser procesada por otros comandos (como xargs -0)
cksum -z archivo.txt
----

--ignore-missing:: `--ignore-missing` Ignorar los archivos que no se encuentran en el disco

[source,bash]
----
# Verificar solo los archivos presentes sin lanzar errores por los ausentes
cksum -c --ignore-missing sumas.txt
----

-b / -t:: `-b` (binary) / `-t` (text) Forzar el modo de lectura del archivo

[source,bash]
----
# Leer el archivo en modo binario (crucial en sistemas no-POSIX/Windows)
cksum -b imagen.png
----
