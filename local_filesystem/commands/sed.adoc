=== sed
Stream Editor: Editor de flujo para filtrar y transformar texto de forma no interactiva.

:category: local_filesystem
[.metadata]
{
  "description": "Lee el texto entrada por entrada (línea a línea), aplica las modificaciones indicadas y devuelve el resultado. Es ideal para ediciones masivas en archivos de configuración o limpieza de logs.",
  "usage": "sed 's/buscar/reemplazar/g' archivo.txt",
  "options": {
    "-i": "In-place: modifica el archivo original directamente (permite crear backup con -i.bak)",
    "-e": "Expression: permite encadenar varios comandos de edición en una sola línea",
    "-n": "Silent: suprime la salida automática (solo imprime lo que se indique con el comando 'p')",
    "-r, -E": "Regexp: habilita el uso de expresiones regulares extendidas (ERE)",
    "-f": "File: lee los comandos de edición desde un archivo externo",
    "-u": "Unbuffered: procesa los datos lo más rápido posible (útil para flujos continuos)",
    "--follow-symlinks": "Si el archivo es un enlace simbólico, edita el destino real en lugar de romper el enlace"
  }
}

[source,bash]
----
# Sustitución básica: cambia la primera aparición de "hola" por "adiós" por cada línea
sed 's/hola/adiós/' saludo.txt
---

[source,bash]
----
# Modificar el archivo y crear una copia de seguridad .old automáticamente
sed -i.old 's/localhost/127.0.0.1/g' config.php
----

-n / p:: Control total sobre qué líneas se muestran.

[source,bash]
----
# Extraer solo las líneas de la 10 a la 20 de un archivo grande
sed -n '10,20p' log_gigante.txt

# Mostrar solo las líneas que contienen la palabra "CRITICAL"
sed -n '/CRITICAL/p' syslog
----

-d:: `-d` (delete) Elimina líneas basándose en su número o en un patrón.

[source,bash]
----
# Eliminar todas las líneas que empiezan por comentario (#)
sed '/^#/d' configuracion.conf

# Eliminar la última línea del archivo
sed '$d' lista.txt
----

-e:: `-e` (expression) permite realizar múltiples ediciones en una sola pasada de lectura del archivo.

[source,bash]
----
# Borrar líneas vacías Y cambiar "provisional" por "final"
sed -e '/^$/d' -e 's/provisional/final/g' documento.txt
----

-r / -E:: Permite usar metacaracteres modernos como `+`, `?` o grupos `()` sin escaparlos con barras invertidas.

[source,bash]
----
# Cambiar formatos de fecha (ej: 2024-03-21 a 21-03-2024) usando grupos
sed -E 's/([0-9]{4})-([0-9]{2})-([0-9]{2})/\3-\2-\1/' fechas.txt
----
