=== gzip
Empaquetamiento de múltiples archivos y directorios.

:category: local_filesystem
[.metadata]
{
  "description": "Empaquetar archivos con compresión gzip.",
  "usage": "gzip [OPCIONES] archivo(s)",
  "options": {
    "-c": "Escribir salida a stdout",
    "-d": "Desempaquetar archivo",
    "-f": "Forzar sobrescritura",
    "-k": "Mantener archivos originales",
    "-9": "Usar máxima compresión",
    "--help": "Mostrar ayuda"
  }
}

[source,bash]
----
# Empaquetar archivos
gzip archivo.tar archivo1 archivo2

# Desempaquetar archivo
gunzip archivo.txt.gz
----

* -c:: `gzip -c` Empaquetar mantieniendo archivos originales
* -9:: `gzip -9` Empaquetar con la maxima compresión posible
