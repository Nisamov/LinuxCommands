=== cp
Copiar archivos y directorios en el sistema de archivos.

:category: local_filesystem

[source,bash]
----
# Copiar un archivo a una nueva ubicación
cp documento.txt /home/usuario/respaldos/
----

-r:: `-r` (o `-R`) Copiar directorios y todo su contenido de forma recursiva

[source,bash]
----
# Copiar una carpeta entera a otro lugar
cp -r /etc/configuracion /backup/central/
----

-f:: `-f` (force) Si el destino no se puede abrir, lo elimina e intenta de nuevo

[source,bash]
----
# Forzar la copia incluso si el destino tiene restricciones de escritura
cp -f sistema.bin /dev/sdb1
----

-a:: `-a` (archive) Preserva enlaces, atributos y copia recursivamente (ideal para backups)

[source,bash]
----
# Copiar manteniendo exactamente la estructura y permisos originales
cp -a /home/usuario /mnt/disco_externo/
----

-b:: `-b` (backup) Realiza una copia de seguridad de los archivos que van a ser sobrescritos

[source,bash]
----
# El archivo original en destino se renombrará (ej: file.txt~)
cp -b nuevo_script.sh /usr/local/bin/script.sh
----

-i:: `-i` (interactive) Solicita confirmación manual antes de destruir datos existentes

[source,bash]
----
# Evitar sobrescribir archivos por error
cp -i foto.jpg /galería/vacaciones/
----

-v:: `-v` (verbose) Muestra el nombre de cada archivo a medida que se procesa

[source,bash]
----
# Ver el progreso de la copia en la terminal
cp -v *.mp3 /musica/pendientes/
----

-u:: `-u` (update) Copia solo cuando el origen es más nuevo o el destino no existe

[source,bash]
----
# Sincronizar archivos modificados recientemente
cp -u *.doc /nube/documentos/
----

-l / -s:: `-l` (link) o `-s` (symbolic link) No copia datos, crea punteros al origen

[source,bash]
----
# Crear un acceso directo en lugar de duplicar el archivo
cp -s /ruta/real/ejecutable /usr/bin/comando
----

-n:: `-n` (no-clobber) Jamás sobrescribe un archivo que ya existe

[source,bash]
----
# Añadir archivos nuevos a una carpeta sin tocar los ya existentes
cp -n * /destino/coleccion/
----

--parents:: `--parents` Recrea la estructura de directorios del origen en el destino

[source,bash]
----
# Creará /backup/var/log/apache2/access.log
cp --parents var/log/apache2/access.log /backup/
----

--preserve:: `--preserve[=ATTR_LIST]` Control fino sobre qué metadatos mantener

[source,bash]
----
# Copiar preservando solo el propietario y los grupos
cp --preserve=ownership archivo.txt /tmp/
----

--reflink:: `--reflink[=always|never]` Realiza copias ligeras en sistemas como Btrfs o XFS

[source,bash]
----
# Copia instantánea que no ocupa espacio extra (Copy-on-Write)
cp --reflink=always base_datos_gigante.db backup_db.db
----

-x:: `-x` (one-file-system) No atraviesa puntos de montaje de otros discos

[source,bash]
----
# Copiar la raíz sin incluir datos de discos externos montados en /mnt o /media
cp -ax / /destino/clon_sistema
----
