=== nl
Numerar las líneas de archivos o de la entrada estándar con opciones de formato.

:category: local_filesystem

[source,bash]
----
# Numerar solo las líneas que contienen texto (comportamiento por defecto)
nl notas.txt
----

-b:: `-b <style>` Define qué líneas del cuerpo reciben un número.

* `a`: Numerar todas las líneas.
* `t`: Numerar solo líneas con texto (default).
* `n`: No numerar ninguna línea.
* `pRE`: Numerar solo líneas que coincidan con la expresión regular `RE`.

[source,bash]
----
# Numerar absolutamente todas las líneas, incluidas las vacías
nl -b a archivo.txt

# Numerar solo las líneas que empiezan por "ERROR"
nl -b p'ERROR' syslog.log
----

-v / -i:: `-v` (start-number) e `-i` (increment) para controlar la secuencia numérica.

[source,bash]
----
# Empezar en 10 e ir de 10 en 10 (10, 20, 30...)
nl -v 10 -i 10 lista.txt
----

-n:: `-n <format>` Controla la alineación y el relleno del número.

[source,bash]
----
# rz (Right justified, Zero padded): Útil para que todo quede alineado en listas largas
nl -n rz -w 4 archivo.txt
# Salida: 0001  Texto...
----

-s:: `-s <string>` Cambia el tabulador por defecto por cualquier otro separador.

[source,bash]
----
# Usar un punto y espacio para un estilo de lista clásica
nl -s ". " poema.txt
----

-w:: `-w <width>` Define el espacio que ocupa la columna del número.

[source,bash]
----
# Reservar solo 2 espacios para el número (máximo 99 líneas bien alineadas)
nl -w 2 datos.csv
----

Secciones de documento:: `nl` reconoce delimitadores especiales para tratar partes del archivo de forma distinta.

[source,bash]
----
# El archivo debe contener estos delimitadores para activar secciones:
# \:\:\:  -> Encabezado
# \:\:    -> Cuerpo
# \:      -> Pie de página

# Numerar el encabezado y el cuerpo de forma distinta
nl -h a -b t documento_complejo.txt
----
