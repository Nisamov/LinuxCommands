=== vgdisplay
Mostrar información detallada de grupos de volúmenes (VG) en LVM.

:category: local_storage
[.metadata]
{
  "description": "Modificar y gestionar grupos de volúmenes en LVM.",
  "usage": "vgdisplay [OPCIONES] [GRUPO]",
  "options": {
    "-l": "Listar grupos de volúmenes",
    "-t": "Cambiar tipo de grupo de volúmenes (modo interactivo)",
    "-n": "Crear nuevo grupo de volúmenes (modo interactivo)",
    "-d": "Borrar un grupo de volúmenes (modo interactivo)",
    "-p": "Mostrar tabla de grupos de volúmenes (modo interactivo)",
    "-v": "Modo verbose para mostrar información adicional",
    "-n nombre": "Filtrar por nombre de grupo de volúmenes",
    "-C": "Salida en columnas (formato compacto)",
    "--units": "Cambiar unidades de tamaño (B, K, M, G, T)",
    "--maps": "Mostrar mapeo de volúmenes lógicos sobre los PV del grupo"
  }
}

[source,bash]
----
# Mostrar todos los grupos de volúmenes del sistema
vgdisplay
----

-v:: `vgdisplay -v` Modo verbose para mostrar información adicional

[source,bash]
----
# Mostrar detalles completos de los VG
vgdisplay -v
----

-n:: `vgdisplay -n nombre` Filtrar por nombre de grupo de volúmenes

[source,bash]
----
# Mostrar información del VG llamado vg1
vgdisplay -n vg1
----

-C:: `vgdisplay -C` Salida en columnas (formato compacto)

[source,bash]
----
# Mostrar VG en formato compacto
vgdisplay -C
----

--units:: `vgdisplay --units` Cambiar unidades de tamaño (B, K, M, G, T)

[source,bash]
----
# Mostrar tamaños en gigabytes
vgdisplay --units G
----

--maps:: `vgdisplay --maps` Mostrar mapeo de volúmenes lógicos sobre los PV del grupo

[source,bash]
----
# Ver cómo los LV ocupan los PV del VG
vgdisplay --maps vg1
----
