`nvme-cli` es el estándar para interactuar con dispositivos PCIe/NVMe, permitiendo desde ver temperaturas hasta gestionar namespaces.

[source,bash]
----
# Listar todas las unidades NVMe instaladas
nvme list
----

smart-log:: `nvme smart-log` Datos de salud
+
[source,bash]
----
# Ver temperatura y vida útil restante
nvme smart-log /dev/nvme0
----

id-ctrl:: `nvme id-ctrl` Información técnica
+
[source,bash]
----
# Ver capacidades del controlador y firmware
nvme id-ctrl /dev/nvme0
----
