=== swapoff
Desactivar áreas de intercambio (swap) en el sistema.

:category: local_storage
[.metadata]
{
  "description": "Modificar y gestionar áreas de intercambio en el sistema.",
  "usage": "swapoff [OPCIONES] [DISPOSITIVO]",
  "options": {
    "-l": "Listar áreas de intercambio",
    "-t": "Cambiar tipo de área de intercambio (modo interactivo)",
    "-n": "Crear nueva área de intercambio (modo interactivo)",
    "-d": "Borrar una área de intercambio (modo interactivo)",
    "-p": "Mostrar tabla de áreas de intercambio (modo interactivo)",
    "-a": "Desactivar todas las áreas de intercambio listadas en /etc/fstab",
    "-v": "Modo verbose para mostrar detalles de la operación",
    "-n": "Simular la desactivación sin aplicarla (dry-run)",
    "device": "Desactivar un swap específico",
    "file": "Desactivar un archivo de swap específico"
  }
}

[source,bash]
----
# Desactivar todo el swap del sistema
swapoff -a
----

-a:: `swapoff -a` Desactivar todas las particiones o ficheros de swap listados en /etc/fstab

[source,bash]
----
# Desactivar todos los swap activos
swapoff -a
----

-v:: `swapoff -v` Modo verbose para mostrar detalles de la operación

[source,bash]
----
# Desactivar swap mostrando información detallada
swapoff -v /dev/sda2
----

-n:: `swapoff -n` Simular la desactivación sin aplicarla (dry-run)

[source,bash]
----
# Probar la desactivación sin apagar el swap
swapoff -n /dev/sda2
----

-device:: `swapoff dispositivo` Desactivar un swap específico

[source,bash]
----
# Desactivar swap en /dev/sda2
swapoff /dev/sda2
----

-file:: `swapoff fichero` Desactivar un archivo de swap específico

[source,bash]
----
# Desactivar swap en un archivo /swapfile
swapoff /swapfile
----
